# Pienotes

The most efficient note taking app for math. Pienotes uses [MathQuill](https://github.com/mathquill/mathquill). MathQuill allows you to type auto commands such as "sqrt" or "int" and automatically convert those into symbols.

## How to use

Ctrl + E = Convert to math block

Shift + Enter = New text line

Type "*text*" to write plain text inside math blocks.

Auto commands work by simply typing the command and it will get replaced with the symbol. For other LaTeX expressions that don't have an auto command you need to use backslash.
